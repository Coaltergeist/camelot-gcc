# Component attribution and notices

This repository vendors GCC 2.96, GCC 3.0 and a pruned pret/agbcc tree. Preserve
upstream authorship and the notices shipped with each source file and component.
The README describes the vendored lineage, pruning and compatibility changes.

Existing component notice files include:

- [GCC 2.96 COPYING](gcc-2.96/COPYING) and [COPYING.LIB](gcc-2.96/COPYING.LIB).
- [GCC 3.0 COPYING](gcc-3.0/COPYING) and [COPYING.LIB](gcc-3.0/COPYING.LIB).
- [agbcc COPYING](agbcc/gcc/COPYING) and [COPYING.LIB](agbcc/gcc/COPYING.LIB).

Additional notices remain within the component subdirectories. This index does
not replace them or introduce a new project-wide license for repository tooling.
License selection for original repository additions remains a maintainer decision.
